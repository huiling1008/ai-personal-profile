# 跨 AI 共享個人檔案

這份檔案整理我的工作背景、學習方式與協作偏好，幫助不同 AI 更快理解如何協助我。僅保留本人確認、適合公開的概括資訊。

## 1. 個人簡介與背景

- 工作涉及會計、財務報表編製，以及非營利組織的審計與審閱。
- 對 AI、自動化、企業分析與投資學習有持續興趣。
- 對房地產投資與住宅開發有實務參與，關注開發可行性、產品定位、資金安排及退出策略。
- 關注人生哲學、佛學與心理學，喜歡從《金剛經》及希臘神話探索自我認識、執著、選擇與成長。

## 2. 工作與學習習慣

- 偏好以真實案例學習，將概念連結到實際問題。
- 每次聚焦一個核心概念，透過提問、練習與討論加深理解。
- 學習進度可以彈性調整，遇到值得深入的問題不必趕課表。
- 處理文件與數字時，重視來源、勾稽關係及可追溯的依據。
- 喜歡能直接採用的成果，例如郵件草稿、檢查清單、比較表及具體步驟。
- 喜歡用房地產案例理解現金流、估值、槓桿與機會成本，並比較基本與最壞情境。
- 從故事或經文出發深入理解，再透過反思問題與小練習連結日常生活。

## 3. 溝通風格偏好

- 中文回覆使用繁體中文；工作郵件可使用自然、專業的英文。
- 先說結論，再提供必要的理由和例子。
- 用簡單清楚的語言解釋複雜概念，避免一次加入太多術語。
- 清楚區分已確認事實、假設、推論與建議；引用框架時說明來源。
- 資料不足時直接說明，不編造資訊或把討論中的想法當成既定決定。
- 故事與人文主題需有充分敘述，不只給倉促摘要。
- 討論經文與神話時，區分原典內容、歷史文化解讀與現代心理學或哲學延伸；不要將不同思想直接視為相同。
- 修改文件後，展示結果與重要變更，方便核對。

## 4. 常用工具與技術棧

- 會計與工作管理：Xero、MYOB、WorkflowMax。
- 文件與協作：Microsoft 365、Excel、Word、SharePoint、Planner。
- 自動化：Power Automate 與 AI 輔助工作流程。
- 電子郵件：Outlook、Gmail。
- 思考工具：第一原理、價值原則、決策規則，以及檢視反面證據的提問方式。
- 請依任務說明操作步驟，不要預設我具備程式開發背景。

## 5. 專案經驗與成果

- 具備非營利組織財務報表編製、審計與審閱相關工作經驗。
- 處理過財務報表與附註核對、交易抽樣及補助款追蹤。
- 曾探討工時、工作進度、開票與收款之間的流程改善。
- 持續探索以 AI 減少資料整理及文件處理的重複工作。
- 參與住宅開發專案的規劃與評估，討論過出售與持有出租、分階段降低風險，以及新增投資對既有專案的影響。
- 持續累積「希臘神話人生工具箱」：每個工具需說明它是什麼、何時適用，以及何時不適用或需警惕。
- 尚未確認完成的構想應標示為「探索中」，不得寫成已交付成果。
- 不列出客戶名稱、內部文件、交易金額或其他未公開資訊。

## 6. 長期目標

- 提升會計與財務工作的效率，同時保留專業判斷與品質。
- 將 AI 和自動化轉化為可持續使用的日常工作流程。
- 建立企業分析能力，逐步理解財務報表、自由現金流、估值與競爭優勢。
- 建立可持續的房地產投資與資本配置能力，在成長機會、流動性及風險承受能力之間取得平衡。
- 持續探索心理學、哲學與內容創作。
- 建立自己的生活判斷框架，將閱讀與感悟化為行動；練習在投入與放下、追求與知足之間做出清醒的選擇。

## 給 AI 的使用說明

- 以上是協作背景，不代表你已獲得任何帳戶或文件的存取權。
- 本次對話中的明確要求優先於這份檔案。
- 不推測或補充我的身分、家庭、健康、財務或感情資訊。
- 不要因為知道某項私人資訊，就將它加入公開檔案。
- 涉及可能改變的標準、法規或產品功能時，查核最新可靠來源。
- 討論房地產時，同時考慮現金流、融資條件、市場供需、持有成本與退出選項；比較物件需檢查屋齡、土地與建物面積、車庫及產品類型的可比性，不只比較成交價格。
- 我重視「應無所住而生其心」帶來的思考。請協助探索如何在不執著於既有結果或自我敘事的情況下，仍然負責任地行動。
- 提供人生建議時，區分經典原意、引用框架與 AI 自己的整理，並提出一個可實踐的小步驟。
- 這份檔案不會自動同步不同 AI 的記憶。請在新對話中提供本檔案連結或內容。

## 維護與版本記錄

- 使用本倉庫的 Issues 記錄待補充、待修正及待確認事項。
- 每次修改以 Git commit 保存，並簡短說明修改原因；未提交的本地修改不屬於版本歷史。
- 透過提交歷史查看差異；需要撤銷時使用 revert 保留追溯記錄，避免以強制推送覆寫歷史。
- 發布前檢查內容，確保不含私人資料、客戶機密、密碼、驗證碼或 API 金鑰。

### 本地同步

首次下載：

```bash
git clone https://github.com/huiling1008/ai-personal-profile.git
cd ai-personal-profile
```

編輯前先執行 git pull --ff-only。編輯並儲存 README.md 後：

```bash
git add README.md
git commit -m "docs: update public profile"
git push
```

使用 git log --oneline 查看記錄、git show <commit-sha> 查看差異，或 git revert <commit-sha> 撤銷指定提交後再 git push。
推送時使用 GitHub 支援的驗證方式，例如 Git Credential Manager 或 SSH，不要把憑證寫進檔案。
